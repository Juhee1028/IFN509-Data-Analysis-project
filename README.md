# IFN509 – Data Exploration & Analysis Project (High Distinction)

## Overview
This repository contains my work for the **IFN509 Data Exploration and Analysis** project at Queensland University of Technology (QUT).  
The project focuses on **data preprocessing, data cleaning, exploratory data analysis (EDA), feature engineering, and statistical insights** using Python.

## My Contributions
- Data cleaning, preprocessing, and handling missing values  
- Outlier detection and transformation  
- Exploratory data analysis (EDA) including summary statistics and correlation analysis  
- Feature engineering (encoding, scaling, transformations)  
- Visualisation using Matplotlib & Seaborn  
- Drafting analytical findings and supporting sections for the final report
